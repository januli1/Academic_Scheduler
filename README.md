# 📚 OptiClass: Academic Scheduler with AI

OptiClass is an intelligent timetable management system that uses AI to generate conflict-free academic schedules. It considers faculty availability, room capacity, and student performance data to optimize class timings.

## 🔧 Tech Stack
- React.js • Node.js • Express.js • MongoDB
- AI Engine: Python (Scikit-learn/TensorFlow)

## 🚀 Features
- AI-powered schedule optimization
- Faculty, room, and course management
- Conflict detection and resolution
